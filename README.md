# 🌐 Personal Portfolio

An interactive personal portfolio website showcasing my skills, projects, experience, and interests in software development and AI/ML.

## ✨ Features

* Responsive personal portfolio
* About Me section
* Skills and technologies
* Projects showcase
* Internship experience
* Contact information
* Interactive web elements
* Three.js-based visual elements

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Three.js

## 📂 Project Structure

```text
Portfolio/
│
├── index.html
├── styles.css
├── main.js
├── three-scene.js
├── sound-fx.js
└── .github/
```

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/anshi102004/Portfolio.git
```

### 2. Open the project

Open the project folder in VS Code or any preferred code editor.

### 3. Run the website

Open `index.html` in a web browser.

For the best experience, you can also run the project using a local development server such as the VS Code Live Server extension.
